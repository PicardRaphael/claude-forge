# Domaine — Discovery (tendances émergentes)

Couvre : nouveaux outils viraux, leaders émergents, papers breakthrough, discussions trending — tout ce qui ne vient PAS d'une source déjà monitorée.
Nombre de queries : 7

## Sources de signal curé par la communauté

- `news.ycombinator.com` — top stories votées
- `reddit.com/r/LocalLLaMA` — communauté IA locale
- `reddit.com/r/MachineLearning` — communauté ML académique
- `paperswithcode.com` — papers trending avec code
- `arxiv.org` — preprints IA

## Queries à exécuter

> Ces queries cherchent ce qu'on NE SURVEILLE PAS encore. Si un résultat est significatif, créer une nouvelle fiche leader ou technique dans le vault.

```
site:news.ycombinator.com (LLM OR fine-tuning OR RAG OR agents) past month
site:reddit.com/r/LocalLLaMA top this week
site:reddit.com/r/MachineLearning top this week
paperswithcode.com trending LLM
"viral" OR "everyone is using" AI tool this month
breakthrough AI paper arxiv this month
new AI startup launch this month
```

## Capitalisation vault

- Nouveau leader découvert → `05-Leaders/<nom>.md`
- Nouvelle technique virale → `04-Techniques/<sous-dossier>/`
- Nouveau produit/outil d'un fournisseur → `<NN>-<Fournisseur>/products/`
