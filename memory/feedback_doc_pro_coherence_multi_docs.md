Quand on produit un ensemble de documents liés (ex : trilogie CODIR Neoteem), une affirmation corrigée dans un doc DOIT être propagée dans les autres. Relire chaque doc en entier (mot à mot) avant de déclarer fini — un chiffre/statut qui dit A dans un doc et non-A dans un autre coule la crédibilité devant un décideur.

**Why:** Session 29 mai — NeoMail disait « back OK » dans l'inventaire mais « à cadrer totalement » dans la timeline ; « Office 365 » faux pour Genius ; double `<thead>`. Raphaël a dû les repérer lui-même.
**How to apply:** Avant de livrer un pack de docs liés au CODIR/client : passe de relecture intégrale de chaque doc + recherche des contradictions inter-docs sur les faits clés (chiffres, statuts, dates).
