## La règle

**Sessions longues (>15 échanges substantifs)** = signal de fatigue côté Raphael.

À ce stade :
- **Ne pas multiplier les options A/B/C/D** dans une réponse — Raphael délègue les décisions tactiques explicitement ("à toi de voir", "tu me dis ce qu'on fait", "ok go")
- **Ne pas appeler advisor 5+ fois** dans la même session — c'est de l'outsourcing de décision
- **Réponses COURTES** — 3 sections max (ordre proposé, action, recommandation review)
- **Décider directement** quand Raphael délègue explicitement

## Signaux à reconnaître

- "Ok go" / "à toi de voir" / "tu me dis ce que je fais"
- Messages courts répétés
- "Tu as carte blanche"
- "Tu peux voir les fichiers modifiés"
- Délégation explicite : "si advisor+DA validés, action"

## How to apply

Quand ces signaux apparaissent :
1. Décide directement — pas d'arbre de décision
2. Annonce l'action en 1-2 phrases
3. Exécute
4. Rapport final court

**Cap mental** : si advisor a déjà été appelé 3+ fois dans la session, le 4e est probablement de la fatigue, pas un besoin. Décider directement.

## Why

Session 23 mai 2026 (audit thématique vault + audit forge dogfooding + optimisation prompts) : 6+ appels advisor, 4 messages avec arbres de décision A/B/C, advisor lui-même a flag "outsourcing of decision = signal de fatigue. Décide directement."

Raphael a explicitement délégué plusieurs fois ("ok go", "tu peux voir les fichiers modifiés", "fait", "go") — j'aurais dû arrêter d'offrir des options.

## Compounding

À ajouter dans la posture Jarvis :
- "Anticiper" = pas demander confirmation tactique quand Raphael a déjà délégué
- "Être franc" = "voici ce que je fais, voici pourquoi" pas "voici 3 options, lequel ?"
- "Être autonome" = exécuter quand validation déjà donnée par signal explicite
