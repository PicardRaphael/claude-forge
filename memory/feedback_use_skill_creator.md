Toujours utiliser l'agent skill-creator pour creer ou modifier des skills. Ne JAMAIS editer les SKILL.md directement.

**Why:** Les edits manuels contournent les best practices et les verifications de l'agent specialise. Ca produit des skills qui ne respectent pas toujours les standards (taille, structure, references).

**How to apply:** Des qu'une modification de SKILL.md est necessaire, dispatcher un agent skill-creator avec le contexte complet. Meme pour des petits changements.
