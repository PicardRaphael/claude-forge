Le vault forge-brain doit suivre le MEME standard de qualite que neoteem-brain. Pas de compromis.

**Why:** Raphael a constate que forge-brain etait tres en dessous de neoteem-brain en qualite : aliases pauvres (2.0 avg vs 5-6), pas de CLI Obsidian, agents qui font du Grep/Read brut, templates pas respectes. Session 8 mai 2026 : audit complet + corrections sur 96 notes.

**How to apply:**
- Aliases : minimum 4-6 par note. Inclure synonymes FR, termes EN, noms techniques, termes de recherche naturels
- Resume : phrase complete et informative, pas juste le titre reformule
- Wikilinks : `[[Note]]` partout, jamais de texte brut pour les liens internes
- Sections template : respecter les templates dans Templates/
- `derniere-maj` : mettre a jour a CHAQUE modification
- CLI Obsidian : search/read/backlinks/property:set, pas Grep/Read brut
- Lien MOC parent obligatoire dans ## Liens
- Tags standardises : `#type/X` + `#domaine/Y`
- Pattern neoteem-brain : Knowledge/questions/, Knowledge/explorations/ pour enrichir
