**Why:** Le 2026-05-07, ajout progressif de Phase C + étape COMPRENDRE + format learnings + causes racines + enrichissement lexique dans triage-tickets. Le fichier a atteint 501 lignes sans que je propose de déporter. Raphael a dû me le signaler — c'est exactement ce qu'un bras droit proactif doit anticiper.

**How to apply:** À chaque ajout de contenu dans un SKILL.md, vérifier la taille AVANT de finir. Si > 430 lignes après modification → proposer proactivement d'extraire dans references/. Ne pas attendre que l'utilisateur remarque le problème.
