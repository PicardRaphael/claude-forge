Le pattern `/loop 1h /brain-check` est une excellente feature de monitoring passif.

**Why:** neo_ia a un écosystème Brain complet (.claude-brain/, observations, instincts, patterns, traps) qui nécessite un monitoring de cohérence. back2.0 utilise `memory: project` natif qui se gère seul — pas besoin.

**How to apply:**
- neo_ia : recommander `/loop 1h /brain-check` pendant les sessions longues
- back2.0 : PAS de brain-check, `memory: project` natif suffit
- Nouveaux projets : recommander `/loop` + skill de monitoring uniquement si le projet a un système de mémoire persistante custom (Brain, instincts)
- Ne jamais copier brain-check dans un projet sans l'écosystème Brain
