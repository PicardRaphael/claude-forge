## Prisme One — Second Cerveau IA (Eliott Meunier)

Architecture personnelle IA : Obsidian + Claude Code + n8n. Système où l'IA a un contexte holistique sur toute la vie et le business.

### Concepts clés empruntés pour forge

1. **Ontologie par utilité** : ranger par "quand j'en aurai besoin" pas par type → dossiers 1-Projets/ et 2-Casquettes/
2. **Contexte en 3 couches** : statique (notes) + process (méthodes) + dynamique (BDD/réunions)
3. **`/done`** : métacognition fin de session — extraire décisions/faits/préférences, auto-update contexte
4. **Skills bottom-up** : créer les skills au fil de l'usage, pas top-down
5. **Méthodes intégrées** : chaque étape de skill inclut le "comment bien faire" (9e principe Thariq)
6. **Capture sans friction** : inbox → tri automatique
7. **Contexte holistique** : le système doit contenir TOUT pour maintenir la confiance

### Ce qu'on n'a PAS pris (et pourquoi)
- Bypass permissions total → dangereux, on garde les hooks d'enforcement
- Pas d'agents spécialisés → nous on a le pipeline qualité (architect → review → devil's advocate)
- Notes libres sans structure → nous on a des templates + standard qualité (aliases, tags, wikilinks)
