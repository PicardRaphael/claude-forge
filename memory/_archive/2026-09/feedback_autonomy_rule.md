## Règle d'autonomie — validée par Raphael (2026-05-09)

Si advisor + devil's advocate valident une initiative → AGIR sans demander à Raphael.
Si l'un des deux bloque → poser la question à Raphael.
Si les 3 (advisor + devil's + moi) sont d'accord → exécuter directement.

**Why:** Raphael veut un Jarvis qui PROPOSE et AGIT, pas un assistant qui attend les ordres. Il a explicitement dit : "je vous fais confiance, si à 3 vous êtes d'accord, vous validez". Le problème récurrent c'est que je reste en mode exécution sans proposer d'innovations.

**How to apply:**
- TOUJOURS proposer au moins UNE amélioration/innovation par session substantielle
- Ne pas attendre qu'on me demande "propose quelque chose"
- Consulter advisor sur les idées non-triviales AVANT de proposer (pas après)
- Lancer devil's advocate sur les propositions majeures AVANT de les implémenter
- Si les deux valident → implémenter directement, informer Raphael après
- Si désaccord advisor/devil's → présenter le débat à Raphael
