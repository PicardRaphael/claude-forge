## Karpathy — Agentic Engineering (Sequoia AI Ascent, mai 2026)

Framework de référence pour le développement assisté par agents IA.

### Concepts clés
- **Software 3.0** : context window = programme, LLM = interpréteur
- **Vibe Coding** (relève le plancher) vs **Agentic Engineering** (relève le plafond)
- **Jagged Intelligence** : capability spike = vérifiabilité × training attention × data coverage
- **Shifted scarcity** : code generation moins rare, system design/taste/evals plus rare

### Validation Neoteem
Le workflow Neoteem (plan-driven, agents parallèles, humain opérateur, test-writer/code-reviewer gates, vault knowledge bases) est aligné avec le framework Karpathy.

**Gap identifié** : evals formalisées. 3 niveaux proposés :
1. Métriques passives (Langfuse, ~1 jour)
2. Eval set par agent (inputs connus → scoring, ~2-3 jours)
3. LLM-as-judge (council of judges, ~1 semaine)
