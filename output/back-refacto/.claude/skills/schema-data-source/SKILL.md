# Schema Data Source Guide

Two primary ways to read the database schema. Use whichever is available.

## Option 1 — MCP PostgreSQL (preferred when available)

If the project has `@modelcontextprotocol/server-postgres` configured in `.mcp.json`:

```sql
-- List all tables
SELECT table_name
FROM information_schema.tables
WHERE table_schema = 'public'
ORDER BY table_name;

-- Inspect a table's columns
SELECT column_name, data_type, is_nullable, column_default
FROM information_schema.columns
WHERE table_name = 'coproprietes'
ORDER BY ordinal_position;

-- Find foreign keys
SELECT
  kcu.column_name,
  ccu.table_name AS foreign_table,
  ccu.column_name AS foreign_column
FROM information_schema.table_constraints AS tc
JOIN information_schema.key_column_usage AS kcu
  ON tc.constraint_name = kcu.constraint_name
JOIN information_schema.constraint_column_usage AS ccu
  ON ccu.constraint_name = tc.constraint_name
WHERE tc.constraint_type = 'FOREIGN KEY'
  AND tc.table_name = 'coproprietes';

-- List all PostgreSQL functions
SELECT routine_name, routine_type
FROM information_schema.routines
WHERE routine_schema = 'public'
  AND routine_name LIKE 'f_%'
ORDER BY routine_name;

-- Read a function's source
SELECT prosrc
FROM pg_proc
WHERE proname = 'f_get_copropriete';
```

## Option 2 — CSV exports (doc/dump/)

Run the export script to generate fresh CSV files:
```bash
.claude/skills/schema-data-source/scripts/export-schema.sh
```

Then read the CSV files:
```
doc/dump/coproprietes.csv     # Column definitions
doc/dump/lots.csv
...
```

CSV format:
```
column_name,data_type,is_nullable,column_default,character_maximum_length
id,integer,NO,,
nom,character varying,NO,,255
syndic_id,integer,YES,,
created_at,timestamp without time zone,YES,now(),
```

## Option 3 — Schema-mapper docs (doc/schemas/)

Pre-generated by the schema-mapper tool. Best for quick domain overview.
See `schema-output-format/SKILL.md` for the format of these files.

## Choosing the right source

| Need | Use |
|---|---|
| Full column list + types | MCP or CSV |
| Relationships (FKs) | MCP query |
| Function source code | MCP (`pg_proc`) |
| Domain overview | doc/schemas/ |
| Offline / no DB access | doc/dump/ CSV |

## After reading the schema

Always update the relevant `doc/schemas/[domain].md` file if you discovered something not yet documented.
