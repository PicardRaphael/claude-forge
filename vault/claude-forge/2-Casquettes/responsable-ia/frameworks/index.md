## Anti-patterns à connaître

| Anti-pattern | Description |
|---|---|
| **HiPPO** | Highest Paid Person's Opinion override la data |
| **Squeaky Wheel** | Le qui crie obtient |
| **ZEBRA** | Bold claim sans evidence |
| **RHINO** | Stakeholder sporadique perturbateur |
| **WOLF** | Pivote sur chaque incident |
| **Roadmap promise** | Dates fermes 6+ mois |
| **Sunk cost fallacy** | "On a déjà investi" |
| **Resume-driven dev** | Stack cool pour CV |
| **Feature factory** | Sortir features pour sortir features |
| **Watermelon project** | Vert dehors, rouge dedans (status reports) |
| **Ruinous Empathy** | Soft sur perf, dur dans la tête (Radical Candor) |
| **Build Trap** | Output > outcome (Perri) |
| **Premature scaling** | Scale avant product-market fit |
