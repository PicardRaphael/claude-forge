# Rétrospective — varier pour ne pas lasser

## TL;DR
- **Catalogue de formats** : Start/Stop/Continue, Mad/Sad/Glad, 4Ls, Sailboat, DAKI, Lean Coffee
- **Rotation tous les 3-4 sprints**, pas chaque sprint (empêche la maîtrise)
- **Action items SMART max 3** par retro (au-delà, rien ne se fait)
- **Audit AIs précédents** au début de chaque retro

## Catalogue des formats

| Format | Quand l'utiliser | Force |
|---|---|---|
| **Start / Stop / Continue** | Débuts, équipes jeunes | Simplicité radicale |
| **Mad / Sad / Glad** | Équipe émotionnellement éprouvée, burnout | Surface l'affect |
| **4Ls** (Liked, Learned, Lacked, Longed for) | Fin de release, milestone | Inclut apprentissage |
| **Sailboat** (vent, ancre, rochers, île) | Vision long terme, stratégie | Métaphore visuelle |
| **DAKI** (Drop, Add, Keep, Improve) | Équipe mature, raffinement process | Action-orientée |
| **Lean Coffee** | Équipe auto-organisée | Agenda émergent + dot vote |

### Détail : Start / Stop / Continue
3 colonnes. Chaque membre poste post-its dans chaque colonne.
- **Start** : ce qu'on devrait commencer à faire
- **Stop** : ce qu'on devrait arrêter
- **Continue** : ce qu'on devrait continuer

**Bon pour** : équipe jeune, retro pour la 1ère fois.

### Détail : Mad / Sad / Glad
- **Mad** : ce qui a frustré
- **Sad** : ce qui a déçu
- **Glad** : ce qui a réjoui

**Bon pour** : période tendue, besoin d'aérer l'affect avant d'aller vers l'action.

### Détail : 4Ls
- **Liked** : ce qui a plu
- **Learned** : ce qu'on a appris
- **Lacked** : ce qui a manqué
- **Longed for** : ce qu'on aurait voulu

**Bon pour** : fin de release, milestone, projet important.

### Détail : Sailboat
Image visuelle d'un bateau qui navigue vers une île :
- **Île** (objectif) : où va-t-on ?
- **Vent** : ce qui nous pousse
- **Ancre** : ce qui nous freine
- **Rochers** : risques à venir

**Bon pour** : retro stratégique, vision moyen terme.

### Détail : DAKI
- **Drop** : à arrêter
- **Add** : à ajouter
- **Keep** : à garder
- **Improve** : à améliorer

**Bon pour** : équipe mature, raffinement continu du process.

### Détail : Lean Coffee
Agenda émergent :
1. Chacun propose des sujets (post-its)
2. Dot voting (3 votes par personne)
3. Top sujets traités dans l'ordre, timebox 5 min par sujet
4. Vote continue/skip à la fin de chaque timebox

**Bon pour** : équipe auto-organisée, focus sur ce qui compte vraiment.

## Rotation recommandée

**Ne pas changer chaque sprint** — ça empêche la maîtrise.

Cycle : **même format 3-4 sprints**, puis switch.

### Combos puissants

- **Mad/Sad/Glad → DAKI** : ouvre par l'émotion, ferme par l'action
- **4Ls** seul en fin de release/projet majeur
- **Sailboat** trimestriel (vision)

## Action items SMART

**Specific** — précis, pas "améliorer la com"
**Measurable** — comment on saura que c'est fait
**Assignable** — 1 owner unique (pas "l'équipe")
**Realistic** — faisable dans le sprint suivant
**Time-boxed** — deadline ferme

**Règle d'or** : max 3 par retro. Au-delà, rien ne se fait.

## Anti-patterns

- ❌ **Blame game** ("c'est la faute de X") — facilitateur doit recadrer immédiatement
- ❌ **Retro sans action items** = thérapie collective sans changement
- ❌ **Action items qui traînent** sprint après sprint sans audit
- ❌ **Toujours le même format** → l'équipe pilote automatique
- ❌ **Retro skippée** quand le sprint a été dur → c'est justement là qu'elle compte

## Agenda type (1h)

| Temps | Activité |
|---|---|
| 0-5 min | Set the stage : énergie équipe, règles de safety |
| 5-10 min | **Audit AIs précédents** : qu'est-ce qui a été fait ? |
| 10-30 min | Generate insights (format au choix) |
| 30-50 min | Decide what to do (action items) |
| 50-55 min | Recap : actions, owners, deadlines |
| 55-60 min | Closing : 1 mot chacun |
