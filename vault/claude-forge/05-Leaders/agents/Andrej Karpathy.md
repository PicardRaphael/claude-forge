### Anti-patterns LLM coding (tweet janvier 2026)
Karpathy liste 4 anti-patterns sans hiérarchie ("#1" est une lecture interprétative communauté, pas Karpathy) :
- **Silent Assumptions** — modèle fait hypothèses implicites sans vérifier
- **Over-Engineering / Overcomplexity** — abstraction prématurée
- **Drive-By Refactoring / Scope Creep** — refacto non demandé
- **Vague Execution** — manque de tradeoffs explicites

### Sequoia AI Ascent (mai 2026)

- 80% de son code est AI-generated
- Framework **Software 3.0** — programmer par contexte, pas par instructions
- Alerte **"jagged intelligence"** — l'IA excelle ou elle a des feedback loops, echoue sur l'ambigu
