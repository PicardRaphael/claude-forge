## Profil

Co-fondateur & CEO de LlamaIndex (créé oct 2022), un des deux frameworks RAG fondateurs. Princeton alumnus. Parcours : Apple, Quora, Two Sigma, Uber.

## Contributions clés

### LlamaIndex
Framework RAG avec 5-10 stratégies de chunking intégrées, hierarchical parent-child comme feature native, Composite Retrieval APIs, `auto_routed` mode.

### Pivot Agentic (2026)
"95% du code LlamaIndex est maintenant généré par IA." Pivot vers **agentic document processing via OCR** — le framework layer devient moins pertinent, le différentiateur est la **qualité du contexte**.

## Positions récentes

**"L'ère des frameworks est terminée — la qualité du contexte est le vrai avantage compétitif."** Les agents ont besoin de déchiffrer les formats de fichiers plus que d'abstractions d'orchestration.
