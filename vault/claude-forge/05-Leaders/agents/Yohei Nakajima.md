## Profil

Né 1987 à Tokyo. BA Economics, Claremont McKenna College (2009). Aucune formation CS — a appris à coder avec des outils IA. 15+ ans de VC/startups. Philosophie : "VC by day, builder by night" + "build-in-public".

## Contributions clés

### BabyAGI (mars 2023)
Premier agent autonome open-source populaire avec planification de tâches. Donner un objectif → l'agent génère sa propre task list, exécute une par une, ajoute de nouvelles tâches selon les résultats. **105 lignes de code.**

**Impact** : **22.3K+ GitHub stars (mai 2026)**, 50+ citations académiques, millions d'impressions. Featured dans Fast Company, Forbes, Business Insider, VentureBeat. A déclenché le mouvement des agents autonomes.

Archivé septembre 2024, relancé comme "self-building autonomous agent" — framework minimal qui se construit et s'améliore lui-même.

### Pattern recognition VC
Sa conviction sur les investissements vient de son expérience directe de builder, pas de pitch decks. Pattern recognition qui se développe des mois avant que les trends soient visibles.

## Importance pour l'écosystème

BabyAGI = patient zéro du mouvement agents autonomes grand public. Le concept de task loop autonome (objective → tasks → execution → new tasks) est devenu un pattern fondamental repris par AutoGPT, CrewAI, et tous les frameworks suivants.
