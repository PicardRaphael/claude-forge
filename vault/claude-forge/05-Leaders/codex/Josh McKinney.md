## Profil

Mainteneur de **Ratatui** — la bibliothèque Rust de référence pour construire des terminal UIs (TUI) — **recruté full-time par l'équipe Codex** d'OpenAI pour y faire de l'open source. Basé à Seattle. Autorité Rust TUI établie AVANT OpenAI : c'est précisément l'expertise que Codex a internalisée puisque sa CLI (~95 % Rust) s'appuie sur Ratatui.

## Contributions clés

- Développement de l'interface terminal de la Codex CLI (Ratatui utilisé directement dans le repo, ex. trait `Stylize`).
- Continuité de la maintenance open-source de Ratatui.
- Ratatui bénéficiaire de l'**OpenAI Codex OSS Fund** (aux côtés de Bun, Apache Maven) — mai 2026.
