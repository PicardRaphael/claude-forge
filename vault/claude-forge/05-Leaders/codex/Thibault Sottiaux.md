## Profil

Ingénieur belge (UCLouvain), ex-Google DeepMind (ML infra, human data, research tools), rejoint OpenAI en 2024. Lead ingénierie de **Codex**, l'agent de code agentique d'OpenAI. Porte la doctrine **"agent-first"** : construire un agent général avant de figer les surfaces produit. Promu en 2026 **GM du core product & platform** (ChatGPT + Codex + API), sous le président Greg Brockman.

## Contributions clés

- Direction technique de Codex depuis le relaunch (agent cloud + CLI Rust + IDE + desktop).
- Choix stratégique **Rust** pour la CLI : *"We debated TypeScript, Go, and Rust... performance at massive scale where every millisecond matters."*
- Doctrine **sandboxing agressif** assumé : *"We take a stance with the sandboxing that hurts us in terms of general adoption."*
- Doctrine **multitasking** : *"Codex is really built for multitasking... most tasks will just get done to completion."*
