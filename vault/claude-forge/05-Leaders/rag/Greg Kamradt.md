## Profil

Créateur indépendant spécialisé dans le RAG et la retrieval. Fondateur de FullStackRetrieval.com.

## Contributions clés

### 5 Levels of Text Splitting
Framework de référence pour le chunking :
1. Fixed-size
2. Recursive
3. Document-based
4. Semantic
5. Agentic

Directement cité dans les papers académiques RAG.

### ChunkViz (chunkviz.com)
Outil de visualisation des text splitters — permet de voir visuellement comment les stratégies de chunking découpent un texte.

### Semantic Chunking
A popularisé l'utilisation de la distance cosinus entre embeddings de phrases consécutives pour détecter les changements de topic.
