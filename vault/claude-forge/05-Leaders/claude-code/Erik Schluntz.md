### Insights cles

1. **"Forget the code, focus on the product"** — le dev devient PM de Claude, pas ecrivain de code
2. **15-20 min de planification** avant chaque tache — explorer le codebase, creer un plan, merger le contexte dans un seul prompt
3. **"Leaf nodes"** — laisser l'IA ecrire les features isolees, garder le controle humain sur le core/design system
4. **22 000 lignes mergees** en prod (codebase RL Anthropic) — 2 semaines compressees en 1 jour
5. **"Demanding to read every line of code will make you the bottleneck"** — analogie LLM = compilateur (comme on a arrete d'ecrire de l'assembly)
