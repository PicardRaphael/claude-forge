# Mitchell Hashimoto

> Co-founder HashiCorp, créateur Ghostty. Popularisateur du terme "harness engineering" en début 2026.

## QUI

Mitchell Hashimoto — Software engineer, co-fondateur HashiCorp (Vagrant, Terraform, Vault, Consul, Nomad, etc.). A quitté HashiCorp en 2023 pour se consacrer à Ghostty (terminal moderne en Zig, **55K+ stars mai 2026**). Site personnel : [mitchellh.com](https://mitchellh.com).

## CE QU'IL APPORTE

### 1. Popularisation "harness engineering" (5 février 2026)

Source : [mitchellh.com/writing/my-ai-adoption-journey](https://mitchellh.com/writing/my-ai-adoption-journey)

Hashimoto a **popularisé** le terme "harness engineering" dans ce post personnel — concept Agent = Model + Harness. Il **hedge lui-même** sur la paternité ("I didn't coin"), mais c'est lui qui a fait connaître le terme à grande échelle.

Le concept a ensuite été :
- Formalisé par **LangChain** (Vivek Trivedy, blog 17 fév 2026)
- Repris par **Birgitta Böckeler** (Thoughtworks, martinfowler.com 2 avril 2026, "guides + sensors")
- Repris par **Addy Osmani** (qualitatif)

### 2. AGENTS.md (spec collective)

`AGENTS.md` proposé comme nom alternatif neutre cross-LLM (Claude Code + Cursor + Gemini CLI + Codex) pour les fichiers de mémoire projet.

**Spec collective août 2025** — pas créé par Hashimoto seul. Spec collective OpenAI / Google / Cursor. Hashimoto en est un porteur, pas l'auteur unique.
