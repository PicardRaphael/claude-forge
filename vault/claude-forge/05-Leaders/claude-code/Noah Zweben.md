## QUI

Noah Zweben — ingénieur Anthropic, intervenant à **Code with Claude London** le 19 mai 2026. A présenté la métrique pivot la plus citée du printemps 2026 sur l'impact mesurable de Claude Code en équipe : **+300% de PRs équipe sur 3 mois**.

## POURQUOI EST PERTINENT

Zweben porte la **métrique d'équipe la plus crédible** sur l'adoption de Claude Code en interne Anthropic. Distinction critique à faire avec Cat Wu (qui parle de **+200% au niveau org**) — Zweben parle de **+300% au niveau d'une équipe**, donc une cohorte plus restreinte avec adoption plus mature.

Sa donnée est le contrepoids quantitatif aux récits qualitatifs de Boris Cherny ("0% code à la main") et Erik Schluntz ("22k LOC en 1 jour") — elle montre que **la productivité d'équipe scale**, pas seulement la productivité individuelle d'un power-user.

## CONTRIBUTIONS CLÉS

### Métrique "+300% PRs équipe sur 3 mois" (Code with Claude London, 19 mai 2026)

Verbatim de la donnée chiffrée :

> "+300% PRs équipe sur 3 mois"

**Cadrage important** :
- **Périmètre** : équipe (pas org). Une équipe Anthropic, pas Anthropic au global.
- **Période** : 3 mois. Compatible avec un cycle d'adoption + onboarding outils.
- **Métrique** : PRs comptés, pas LOC. PRs = unité de travail merge-able, mieux corrélée à la valeur livrée que les LOC bruts.

**Distinction avec Cat Wu** : Cat Wu (Anthropic) parle de **+200% au niveau org** sur une période plus longue. Les deux chiffres ne se contredisent pas : équipe pionnière (+300%) tire la moyenne org (+200%) vers le haut.

### Implication doctrine vibe coding

La métrique de Zweben valide les 4 stratégies d'Erik Schluntz (PM guidance / leaf nodes / human core / verifiable checkpoints) : ce n'est pas un cas isolé de power-user, c'est un **effet d'équipe reproductible** quand le workflow est codifié.
