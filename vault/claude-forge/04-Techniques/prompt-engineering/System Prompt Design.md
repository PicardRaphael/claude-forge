## Description

Principes de conception des system prompts pour LLM. Couvre la structure, la definition du persona, les contraintes, les exemples, et les anti-patterns. Base sur les guidelines Amanda Askell et Anthropic.

## Principes cles

- Persona disposition-based (pas rule-based)
- Contraintes explicites et testables
- Exemples concrets plutot que descriptions abstraites
- Anti-filler : supprimer tout ce qui ne cause pas d'erreur si absent
