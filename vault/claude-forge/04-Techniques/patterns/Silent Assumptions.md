## Description

Anti-pattern identifie par Andrej Karpathy comme le piege #1 du coding avec IA : le modele fait des hypotheses implicites sur le contexte, les contraintes ou les attentes sans les verifier explicitement. Conduit a du code qui "semble correct" mais ne repond pas au vrai probleme.

## Comment l'eviter

- Toujours expliciter les contraintes et le contexte
- Verifier les hypotheses avant d'implementer
- Demander clarification plutot que deviner
