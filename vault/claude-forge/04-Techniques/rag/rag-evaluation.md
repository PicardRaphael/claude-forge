## Description

Metriques et frameworks pour evaluer la qualite d'un systeme RAG. Couvre les dimensions cles (faithfulness, relevance, answer correctness) et les outils (RAGAS, DeepEval, LLM-as-judge).

## Metriques principales

- **Faithfulness** — la reponse est fidele aux documents retrouves
- **Relevance** — les documents retrouves sont pertinents pour la question
- **Answer Correctness** — la reponse est factuellement correcte

## Frameworks

- RAGAS — metriques automatisees, LLM-as-judge
- DeepEval — framework Python, metriques composables
- LLM-as-judge custom — evaluation par modele avec criteres specifiques
