## Description

ColPali est un modele de retrieval multimodal qui traite les documents comme des images plutot que comme du texte. Elimine le pipeline parsing/OCR/chunking en utilisant directement la representation visuelle du document pour le retrieval.

## Avantages

- Pas de pipeline OCR/parsing
- Gere nativement tableaux, graphiques, layouts complexes
- Performances superieures sur documents structures
