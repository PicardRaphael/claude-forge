# Claude Reflect

Annoncé le **9 juillet 2026**. Dashboard intégré à claude.ai qui visualise l'usage de Claude par l'utilisateur : sujets discutés, patterns d'usage globaux, types de tâches déléguées. Extension annoncée : vue du **temps passé** sur Claude.

- **Disponibilité** : beta Free / Pro / Max, uniquement si **memory est activée** (les données viennent de là)
- **Lecture critique** (TechCrunch, 9 juil.) : « quietly selling you on AI » — le dashboard fonctionne aussi comme mécanisme d'engagement/rétention, montrant à l'utilisateur sa propre dépendance croissante

## Pertinence forge

Premier produit Anthropic de **métacognition d'usage** côté utilisateur — même famille conceptuelle que la boucle `/done` + `usage_stats` du vault forge (mesurer son propre usage pour l'améliorer). À surveiller si une API expose ces données.
