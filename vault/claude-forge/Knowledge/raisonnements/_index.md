## Description

Ce dossier contient les chaines de raisonnement validees, indexees par type de probleme.

## Qui ecrit ici

- Skill `/reasoning-cache` — sauvegarde les raisonnements complexes pour reutilisation future

## Quand creer une note

Apres la resolution d'un probleme complexe (multi-etapes, decision d'architecture, analyse strategique), si le raisonnement est reproductible et reutilisable.

## Format des notes

Template : `Templates/raisonnement.md`

Chaque note = un raisonnement valide, avec :
- Contexte du probleme
- Chaine de raisonnement
- Decision finale
- Validation (tests, resultats)
