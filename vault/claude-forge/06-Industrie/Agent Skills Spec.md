## Contexte

Spécification ouverte pour les skills d'agents IA cross-platform. Initiée via `gh skill` de GitHub Copilot.

## Découvertes

- **`gh skill`** command : discover/install/publish
- Compatible Claude Code, Copilot, Cursor, Codex, Gemini CLI
- Convergence industrie vers un format commun de skills
- YAML frontmatter = format de facto pour les agents

## Implications

- Les skills deviennent portables entre outils
- Un écosystème commun réduit le vendor lock-in
- Le format YAML frontmatter de Claude Code devient standard
