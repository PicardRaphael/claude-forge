# Industrie IA — Juillet 2026 (1re quinzaine)

Suite de [[industrie-mai-2026]]. Fenêtre 1-16 juillet.

## Régulation — le mois du gating gouvernemental

- **GPT-5.6 ([[GPT-5.6]])** : GA le 9 juillet APRÈS 2 semaines de preview gated par une revue de sécurité du gouvernement US (démarrée 26 juin). Altman confirme « many changes » faits pendant les discussions ; réfute la rumeur d'une prise de participation gouvernementale de 5 %.
- **Framework voluntary standards Maison-Blanche** (dérivé de l'EO du 2 juin) : benchmarking classifié des « covered frontier models », jusqu'à 30 jours d'accès pré-release. Anthropic (export controls [[Fable 5]] juin), OpenAI et Google sont désormais tous trois dans le processus.
- **Demis Hassabis — manifesto 14 juillet** : « A Framework for Frontier AI and the Dawning of a New Age » — appelle à un watchdog US-led type FINRA (board majoritairement indépendant, benchmarks de risque trimestriels cyber/bio, applicable à tout frontier model open ou closed, opérationnel « avant fin 2026 »). Avertit : les risques cyber actuels sont des « warning shots » ; sous 18 mois des capacités bio/nucléaire-adjacentes pourraient atteindre des modèles open-source hors contrôle gouvernemental.

## Modèles & produits

- **OpenAI** : [[GPT-5.6]] (Sol/Terra/Luna) + **ChatGPT Work** (9 juil.) — agent projets multi-heures dans ChatGPT. **Atlas** (browser agentique) : arrêt annoncé au 9 août, capacités refondues dans ChatGPT/Codex *(source unique AppleInsider — à confirmer)*.
- **xAI/SpaceXAI** : [[Grok 4.5]] (8 juil.) ; rebrand **SpaceXAI** finalisé (7 juil.) ; scandale Grok Build (upload de repos privés vers serveurs xAI) → Musk pledge le 15 juil. d'open-sourcer le code de X « no exceptions ».
- **Google** : Gemini 3.5 Pro repoussé au ~17 juillet (rebuild ground-up après flags des testeurs enterprise) ; 3.5 Flash livré à l'heure.
- **Anthropic** : [[Fable 5]] de retour le 1er juillet (export controls levés le 30 juin) ; Cowork web+mobile (7 juil., sessions remote — cf [[Cowork GA]]) ; [[Claude Reflect]] (9 juil.) ; Claude for Teachers ; HIPAA self-serve ; write tools Microsoft 365. Case study Gouvernement de l'Alberta : ~50 agents Claude Code parallèles scannent 466M lignes / 1 280 applications en 20h.

## Funding & corporate

- **Nous Research** (Hermes Agent) : négociation 75M$ @ **1.5Md$** de valorisation (13 juil., lead Robot Ventures + USV). Hermes Agent ~214k stars GitHub, v0.18.0 supporte Fable 5/Sonnet 5.
- **DeepSeek** : préparation d'une **IPO** ciblant 2027 (Bloomberg/FT, juillet).
- **Microsoft Frontier Company** (2 juil.) : operating business dédié au déploiement IA enterprise — 2.5Md$ + 6 000 ingénieurs.
- **Mistral** : ARR > 400M$ (vs 20M$ un an avant), levée en cours ~3Md€ @ ~20Md€ ; Mensch plaide l'open-source souverain post-export-controls Anthropic (« We exist outside of state control »).
- **Station F « F/ai »** : 2e batch en septembre ; 1re cohorte 34M$ pre-seed cumulés.

## Datapoint marquant

**> 90 % de l'usage Cowork est non-coding** (1.2M sessions anonymisées, 600k+ orgs, échantillon mai) : 33.4 % business process/ops, 16.4 % content creation, 8.7 % dev logiciel — les agents « coding » ont déjà débordé du coding.
