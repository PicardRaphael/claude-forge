## Vue d'ensemble

Assistant IA de GitHub, intégré à VS Code, CLI, et github.com. Multi-modèle (GPT, Claude, Codex).

## Features clés

- **Autopilot** — Agent autonome, sessions isolées (public preview)
- **`gh skill`** — Discover/install/publish skills cross-platform (spec ouverte CC/Cursor/Codex/Gemini)
- **Remote CLI Sessions** — Pilotage web/mobile, QR code
- **Data Residency** US + EU + FedRAMP Moderate
- **Auto model selection** GA en CLI
- **Nested subagents**
- Image/video dans chat
- **Claude Opus 4.7** disponible (7.5x premium multiplier jusqu'au 30 avril)

## Dernières mises à jour

- **20 avril** : **Plans individuels (Student/Pro/Pro+) nouvelles inscriptions suspendues**
- **14 avril** : Model Selection, CLI v1.0.26
- **13 avril** : Remote CLI Sessions, Data Residency
