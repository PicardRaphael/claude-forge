## Profil

IDE IA base sur VS Code fork. Cursor 3 (2 avril 2026) = refonte majeure.

## Features clés

- **Agents Window** — Multi-agents parallèles dans des panneaux
- **Design Mode** — Edit UI en langage naturel
- **Background/Cloud Agents** — Branches isolées, trigger depuis phone/Slack/GitHub
- **Canvases** (15 avril) — Artefacts interactifs (dashboards, diagrammes, charts, tables, diffs)
- **`/worktree`** et **`/best-of-n`** commands
- **Bugbot** — Auto-amélioration via feedback PR, 80% résolution
- Real-time RL pour Composer

## Cursor 3.3 — Mai 2026

- **PR Review intégré** — review de pull requests directement dans Cursor, sans quitter l'IDE
- **Parallel Agents** — subagents asynchrones lancés en parallèle depuis la session principale
- **Visual Canvases** — dashboards, charts, diagrammes comme artefacts durables (persistants entre sessions)
- **Team Marketplace** — partage de snippets, templates, configs au sein d'une équipe
- **Enterprise controls** — contrôles de gouvernance avancés pour les organisations
