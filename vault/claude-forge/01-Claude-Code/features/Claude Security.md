# Claude Security

## Statut

- **Beta publique** depuis le 1er mai 2026
- Disponible pour **Enterprise** uniquement (Team/Max a venir)
- Anciennement "Claude Code Security" (research preview fevrier 2026)
- Propulse par **Opus 4.7**

## Acces

- Sidebar claude.ai ou claude.ai/security
- Pas d'integration API ou agent custom requis

## Features

- **Scans planifies** — monitoring continu, pas juste one-shot
- **Scanning par repertoire** — cibler repos ou sections specifiques
- **Triage avance** — raisons de dismiss documentees
- **Exports** — CSV et Markdown pour compliance/reporting
- **Webhooks** — alertes temps reel via Slack, Jira, etc.
- **Verification multi-etapes** — Claude challenge ses propres resultats avant de les surfacer
- Comprend le contexte, trace les data flows cross-files, detecte les patterns multi-composants
